# 21 Savage Auth

A full-stack message board with user authentication. Sign up or log in, post a message, 
read what others have posted, like or dislike messages with a running count, and delete messages.

## Live Link

[21 Savage Auth](https://savage-auth-ey18.onrender.com/)

## Features

- Sign up and log in
- Post a message
- Read messages from other users
- Like and dislike messages, with a counter for each
- Delete messages

## Built With

- HTML, CSS, JavaScript
- Node.js and Express
- MongoDB

## Installation

1. Clone the repo
2. Run `npm install`

## Usage

1. Run `node server.js`
2. Go to `localhost:8080`
